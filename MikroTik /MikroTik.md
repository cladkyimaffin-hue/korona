**Шаг 1.8 — Генерация ключей WireGuard для MikroTik (сервер)**

**Объяснение/Действие:**
WireGuard работает на основе криптографических ключей (пара: закрытый + открытый ключ). Каждый участник (сервер и клиент) имеет свою пару ключей. Первый шаг — сгенерировать ключи для самого MikroTik, который будет выступать сервером.

1. В левом меню WinBox нажми **New Terminal** — откроется окно терминала.
2. Введи команду для генерации ключей:
   ```
   /interface wireguard keys generate
   ```
3. После выполнения введи команду, чтобы увидеть сгенерированные ключи:
   ```
   /interface wireguard keys print
   ```

В ответ ты увидишь две строки:
- **private-key** — закрытый ключ MikroTik (никому не показывать)
- **public-key** — открытый ключ MikroTik (его нужно будет указать на клиенте)

**Протокол:**
