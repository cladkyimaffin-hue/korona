### Шаг 6.1 — Обзор прав для диагностики SQL Server

Для полноценной диагностики SQL Server существует иерархия прав. Выдавать их нужно по **принципу наименьших привилегий** — только то, что реально требуется для ваших конкретных задач.

---

####  Уровень 1 — Базовая диагностика (уже есть + одно дополнение)

| Право | Что дает | Нужно ли вам |
|---|---|---|
| `CONNECT SQL` | Подключение к инстансу | ✅ Уже выдано |
| `VIEW SERVER STATE` | DMV уровня сервера: `sys.dm_os_*`, `sys.dm_exec_*`, `sys.dm_io_virtual_file_stats`, `sys.dm_tran_*`, `sys.dm_lock_*`, запросы к `sys.dm_exec_requests` (кто что выполняет прямо сейчас) | ✅ Уже выдано |
| **`VIEW DATABASE STATE`** | DMV уровня базы данных: `sys.dm_db_index_physical_stats`, `sys.dm_db_missing_index_details`, `sys.dm_db_index_usage_stats`, `sys.dm_db_partition_stats`. **Без этого права** многие DMV в контексте конкретной БД вернут `NULL` или пустой результат. | ⚠️ **Скорее всего нужно** — это самое частое «следующее» право после `VIEW SERVER STATE` |

**Скрипт для выдачи на уровне всех баз данных:**
```sql
-- Выдаём VIEW DATABASE STATE во всех пользовательских БД
DECLARE @sql NVARCHAR(MAX) = N'';
```
