## Этап 1. Первоначальная диагностика портов и устройств

| Команда | Назначение |
|---------|-----------|
| `/interface ethernet print` | Просмотр всех физических портов, их статуса (R — running, X — disabled) и скорости |
| `/interface ethernet monitor ether2` | Мониторинг состояния конкретного порта в реальном времени |
| `/interface bridge host print` | Таблица MAC-адресов, которые видит мост (кто подключен к какому порту) |
| `/interface bridge host print where interface=bridge1` | Фильтр таблицы хостов по конкретному мосту/порту |
| `/ip dhcp-server lease print` | Список выданных DHCP-аренд (IP ↔ MAC ↔ имя устройства) |
| `/ip dhcp-server lease print where mac-address=58:04:4F:EE:25:92` | Поиск конкретного устройства по MAC в DHCP |
| `/ip arp print` | ARP-таблица (IP ↔ MAC ↔ интерфейс) |
| `/ip arp print where mac-address=58:04:4F:EE:25:92` | Поиск IP устройства по MAC |
| `/tool mac-scan interface=ether3` | Сканирование MAC-адресов на конкретном порту (поиск устройств без DHCP) |

## Этап 2. Диагностика коммутатора TP-Link SX3008F на порту sfp11

| Команда | Назначение |
|---------|-----------|
| `/ip arp print where address=192.168.202.202` | Проверка, есть ли старый IP коммутатора в ARP |
| `/ip arp print where address=192.168.200.3` | Проверка ARP для другого адреса |
| `/ip dhcp-server lease print where mac-address=58:04:4F:EE:25:92` | Поиск коммутатора в DHCP-арендах |
| `/interface ethernet print where name=sfp11` | Статус порта sfp11 (флаг R — линк активен) |
| `/interface bridge port print where interface=sfp11` | В каком мосту находится порт sfp11 |
| `/interface vlan print where interface=sfp11` | Есть ли VLAN-интерфейсы на sfp11 |
| `/ip arp print where mac-address=58:04:4F:EE:25:92` | Поиск IP коммутатора в ARP |
| `/tool mac-scan interface=sfp11` | **Ключевая команда** — показала, что коммутатор отвечает с IP `192.168.0.1` |

## Этап 3. Попытки настроить доступ к коммутатору

| Команда | Назначение | Результат |
|---------|-----------|-----------|
| `/ip address add address=192.168.0.2/24 interface=bridge1 comment="Management SX3008F"` | Попытка добавить IP на bridge1 | ️ Ошибка: мост называется `bridge`, а не `bridge1` |
| `/ip address add address=192.168.0.2/24 interface=bridge comment="Management SX3008F"` | Добавление IP на правильный мост `bridge` | ✅ Выполнено |
| `/ip address add address=192.168.0.2/24 interface=vlan40-bridge comment="Management SX3008F VLAN40"` | Добавление IP на VLAN-интерфейс | ✅ Выполнено (позже удалено) |
| `/interface vlan add interface=sfp11 vlan-id=40 name=vlan40-bridge` | Создание VLAN 40 на порту sfp11 | ✅ Выполнено (позже удалено) |
| `/ping 192.168.0.1 count=4` | Проверка связи с коммутатором | ❌ Не прошел (изоляция L2) |

## Этап 4. Проверка и исправление конфигурации мостов

| Команда | Назначение |
|---------|-----------|
| `/ip address print where interface=bridge1` | Проверка IP на bridge1 (вывод пуст) |
| `/ip address print` | Все IP-адреса на всех интерфейсах |
| `/interface bridge port print where interface=ether1` | Проверка, в каком мосту ether1 |
| `/interface bridge port print where interface=sfp11` | Проверка, в каком мосту sfp11 |
| `/interface bridge port set [find interface=sfp11] bridge=bridge` | Попытка перенести sfp11 в мост bridge |

## Этап 5. Удаление лишних IP-адресов (откат)

| Команда | Назначение | Результат |
|---------|-----------|-----------|
| `/ip address remove [find address=192.168.0.2/24 interface=bridge]` | Удаление IP с bridge | ❌ Не сработало |
| `/ip address remove [find address=192.168.0.2/24 interface=vlan40-bridge]` | Удаление IP с vlan40-bridge | ❌ Не сработало |
| `/interface vlan print where name=vlan40-bridge` | Проверка существования VLAN-интерфейса | ✅ Найден |
| `/interface vlan remove [find name=vlan40-bridge]` | Удаление VLAN-интерфейса | ✅ Выполнено |
| `/ip address remove [find id=1]` | Попытка удаления по id | ❌ Неверный синтаксис |
| `/ip address remove [find id=2]` | Попытка удаления по id |  Неверный синтаксис |
| `/ip address print .id` | Попытка получить внутренние id | ❌ Неверный синтаксис |
| `/ip address print id` | Попытка получить id | ❌ Неверный синтаксис |
| `/ip address print detail` | ✅ Правильная команда для получения внутренних id | ✅ Показала записи #0, #1, #2 |
| `/ip address remove 2` | Удаление записи #2 (невалидная, интерфейс *F) | ✅ Выполнено |
| `/ip address remove 1` | Удаление записи #1 (192.168.0.2 на bridge) | ✅ Выполнено |
| `/ip address print` | Финальная проверка | ✅ Остался только 192.168.200.3/22 |

## Сводная таблица ключевых выводов

| Факт | Подтверждение |
|------|---------------|
| Мост называется **`bridge`**, не `bridge1` | `/interface bridge port print` |
| Управление идет через `ether1` (IP 192.168.200.3/22) | `/ip address print` |
| Коммутатор SX3008F имеет IP **192.168.0.1** | `/tool mac-scan interface=sfp11` |
| Коммутатор шлет трафик с **VLAN 40** | Torch (скриншот) |
| Порт `sfp11` находится в мосту `bridge` | `/interface bridge port print where interface=sfp11` |
| MAC-адрес коммутатора **не виден** в таблице хостов моста | WinBox → Bridge → Hosts |
