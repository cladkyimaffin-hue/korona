# 📁 Индекс папки: srv (Серверы)

**Описание:** База знаний по аудиту, конфигурации и обслуживанию серверной инфраструктуры (Windows Server, Linux), включая анализ ролей, служб и прикладного программного обеспечения.

## 📄 Список файлов и их назначение

1. [Аудит сервера Windows Server 2019 krnn-ru.md](./%D0%90%D1%83%D0%B4%D0%B8%D1%82%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0%20Windows%20Server%202019%20krnn-ru.md)
   - **Краткое содержание:** Детальный аудит сервера `KORONA` в домене `krnn.ru`, выявление его реальной роли и установленного ПО.
   - **Ключевые этапы:** 
     - Опровержение гипотезы о том, что сервер является контроллером домена (роль AD DS установлена, но не настроена, файл `ntds.dit` отсутствует).
     - Фиксация концепции "всё в одном": сервер совмещает функции терминального доступа (полный стек RDS), СУБД (MS SQL Server 2019), платформы 1С:Предприятие (8.3.27.2214), файлового хранилища (DFS, FSRM) и веб-сервера (IIS).
     - Учет специализированного ПО: СКУД SIGUR Access Management, АСКОН ЛОЦМАН:PLM/КБ, Mobile SMARTS, системы видеонаблюдения (Guarding Vision, iVMS).
   - **Ключевые теги:** `KORONA`, `krnn.ru`, `1C`, `SQL-Server`, `RDS`, `СКУД`.
