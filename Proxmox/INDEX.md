# 📁 Индекс папки: Proxmox VE

**Описание:** База знаний по развертыванию, настройке и обслуживанию кластеров Proxmox VE, включая работу с QDevice, Ceph, сетевой инфраструктурой (SDN, 10G SFP+) и устранение типичных неполадок.

## 📄 Список файлов и их назначение

1. [pve01+pve02+Qdevice.md](./pve01%2Bpve02%2BQdevice.md)
   - **Краткое содержание:** Подробный разбор меню Datacenter и HA в Proxmox VE.
   - **Ключевые этапы:** Настройка кворума и отказоустойчивости для кластера из 2 нод с использованием QDevice.

2. [web меню.md](./web%20%D0%BC%D0%B5%D0%BD%D1%8E.md)
   - **Краткое содержание:** Описание подсистемы SDN (Software Defined Networking).
   - **Ключевые этапы:** Настройка зон (Zones), виртуальных сетей (VNets), управления IP-адресами (IPAM) и глобальных параметров.

3. [Добавить qdevice.md](./%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C%20qdevice.md)
   - **Краткое содержание:** Пошаговая инструкция по настройке Corosync QDevice.
   - **Ключевые этапы:** Установка `corosync-qnetd` на отдельный третий хост (ПК) и подключение его к двухузловому кластеру Proxmox для сохранения кворума.

4. [Железа серверов подборка коммутаторов.md](./%D0%96%D0%B5%D0%BB%D0%B5%D0%B7%D0%B0%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%BE%D0%B2%20%D0%BF%D0%BE%D0%B4%D0%B1%D0%BE%D1%80%D0%BA%D0%B0%20%D0%BA%D0%BE%D0%BC%D0%BC%D1%83%D1%82%D0%B0%D1%82%D0%BE%D1%80%D0%BE%D0%B2.md)
   - **Краткое содержание:** Подбор сетевого оборудования для объединения серверов.
   - **Ключевые этапы:** Оценка совместимости коммутаторов (MikroTik, Ubiquiti, QNAP, TP-Link) с модулями Intel 10G SFP+ (FTLX8571D3BCVIT1) и выбор оптических патч-кордов OM3 LC-LC.

5. [Поменять имя устройства на pve01.md](./%D0%9F%D0%BE%D0%BC%D0%B5%D0%BD%D1%8F%D1%82%D1%8C%20%D0%B8%D0%BC%D1%8F%20%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D0%B0%20%D0%BD%D0%B0%20pve01.md)
   - **Краткое содержание:** Инструкция по безопасному переименованию ноды Proxmox.
   - **Ключевые этапы:** Правка `/etc/hosts` и `/etc/hostname`, перезагрузка и миграция папки конфигураций VM в `/etc/pve/nodes/`.

6. [Проблемы с доступом по SSH на Debian.md](./%D0%9F%D1%80%D0%BE%D0%B1%D0%BB%D0%B5%D0%BC%D1%8B%20%D1%81%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BE%D0%BC%20%D0%BF%D0%BE%20SSH%20%D0%BD%D0%B0%20Debian.md)
   - **Краткое содержание:** Устранение неполадок с удаленным доступом.
   - **Ключевые этапы:** Настройка `PermitRootLogin`, проверка статической конфигурации сети вместо DHCP.

7. [Скрипт pstInstal после установки Proxmox.md](./%D0%A1%D0%BA%D1%80%D0%B8%D0%BF%D1%82%20pstInstal%20%D0%BF%D0%BE%D1%81%D0%BB%D0%B5%20%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B8%20Proxmox.md)
   - **Краткое содержание:** Пояснение финального сообщения установщика Proxmox VE.
   - **Ключевые этапы:** Информирование о подписках и рекомендуемые первые команды (`apt update`, `apt full-upgrade`).

8. [Создание Ceph №1.md](./%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5%20Ceph%20%E2%84%961.md)
   - **Краткое содержание:** Теория и практика развертывания гиперконвергентного хранилища Ceph.
   - **Ключевые этапы:** Обоснование необходимости NVMe для WAL/DB при использовании HDD, пошаговое создание MON, MGR, OSD, Pools и настройка High Availability (HA).
