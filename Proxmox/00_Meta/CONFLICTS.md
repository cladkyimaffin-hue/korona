# ⚠️ CONFLICTS.md — очередь неразрешённых противоречий

Сюда конвейер записывает найденное расхождение **вместо** того, чтобы тихо
исправлять один из документов. Запись остаётся здесь до вашего решения,
затем переносится в `CHANGELOG.md` как `conflict-resolved` и удаляется отсюда.

Также сюда попадают breaking change в `SCHEMA.md` (см. `SCHEMA.md`, раздел 3,
пункт 4) — как частный случай противоречия «старая версия правила vs новая».

## Формат записи

```
### [НЕРЕШЕНО] <короткое название конфликта>
- Дата обнаружения: ГГГГ-ММ-ДД
- Источник A: <document_id / файл>, утверждает: "..."
- Источник B: <document_id / файл>, утверждает: "..."
- Почему это противоречие, а не дополнение друг друга: ...
- Предлагаемое решение (не применено): ...
```

После вашего ответа запись перемещается в архив ниже с пометкой `[РЕШЕНО]`
и итоговым решением.
