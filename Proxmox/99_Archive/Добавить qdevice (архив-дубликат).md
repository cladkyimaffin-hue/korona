# [АРХИВ] Настройка Corosync QDevice — обобщённый черновик

**Этот документ архивный и не поддерживается.** Используйте вместо него
**`PROXMOX-CLUSTER-QDEVICE-SETUP-2026-001`**
(`02_Installation/Создание кластера и QDevice.md`) — там реально
выполненная настройка с реальными IP и подтверждённым результатом.

## Почему этот файл в архиве
Исходный файл («Добавить qdevice.md») был сгенерирован как обобщённая
инструкция-заметка (в формате для Obsidian) с плейсхолдером `<IP_QDEVICE>`
вместо реального адреса. Собственные метаданные исходного файла прямо
указывали: *«исходный файл содержит инструкцию и ожидаемые результаты, но
не содержит полного фактического вывода успешной настройки»*. Это привело
к дублированию `document_id` с реально выполненным документом
(`pve01+pve02+Qdevice.md`).

## Что из него не потерялось
Две полезные детали, отсутствовавшие в основном документе, перенесены в
`PROXMOX-CLUSTER-QDEVICE-SETUP-2026-001`:
- Требование доступности TCP-порта **5403** между узлами и QDevice.
- Явное предупреждение: QDevice не заменяет fencing и не решает кворум Ceph.

Остальное содержимое (общая теория QDevice, форматирование для Obsidian)
не перенесено — не несёт дополнительной фактической ценности сверх
основного документа.
