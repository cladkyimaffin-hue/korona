# 00_Inbox

Сюда кладётся сырой, необработанный материал (заметка, вывод команд, кусок
переписки, набросок) — без форматирования, без фронтматтера, как есть.

Дальше конвейер (см. `AI-INSTRUCTIONS.md`, раздел «Протокол конвейера», и
`00_Meta/SCHEMA.md`) забирает файл отсюда, классифицирует, проверяет на
противоречия с существующими документами, присваивает `document_id` и теги,
переносит в целевую категорийную папку, обновляет `registry.csv` и
`CHANGELOG.md`. После переноса исходник здесь не остаётся.

Эта папка в норме почти всегда пустая — непустая означает, что есть
необработанный материал, ожидающий разбора.
