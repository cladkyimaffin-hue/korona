# План миграции ВМ для изоляции 1С ERP

## 1. Контекст и цель
- **Окружение:** Proxmox VE 9.2.11, 2 узла: `pve01`, `pve02`. Ceph-кластер (4 OSD).
- **Проблема:** Пользователи жалуются на «тормоза» 1С ERP (`srv1c`). Анализ показал эффект «шумного соседа»: все ВМ (включая 1С) размещены на `pve01`, который загружен на ~200 GiB RAM из 250 GiB. Узел `pve02` практически свободен (~14 GiB RAM из 250 GiB).
- **Цель:** Обеспечить монопольное использование ресурсов `pve01` для критичной ВМ 1С ERP, мигрировав все остальные ВМ на `pve02`.
- Метки достоверности: VERIFIED — подтверждено выводом команд; INFERRED — вывод; UNKNOWN — данных нет.

## 2. Текущее распределение ресурсов (2026-10-08)

| Узел | RAM Total | RAM Used | RAM Free | Роль |
|---|---|---|---|---|
| `pve01` | 250 GiB | ~200 GiB | ~50 GiB | Хостит все ВМ, включая проблемную 1С ERP. |
| `pve02` | 251 GiB | ~14 GiB | ~236 GiB | Практически свободен, готов принять нагрузку. |

## 3. Стратегия миграции

1. **Идентификация компонентов 1С:** Точно определить, какие ВМ относятся к инфраструктуре 1С (часто это `srv1c-app` и `srv1c-db`, либо одна ВМ `srv1c`). Эти ВМ **остаются на pve01**.
2. **Инвентаризация остальных ВМ:** Получить список всех остальных запущенных ВМ на `pve01` через `qm list`.
3. **Проверка совместимости:** Убедиться, что `pve02` имеет достаточно ресурсов (RAM, CPU, место на Ceph) для приема мигрируемых ВМ.
4. **Пошаговая миграция:** Выполнять миграцию по одной ВМ (или логическими группами) в нерабочее время или в период низкой нагрузки, используя `qm migrate <vmid> pve02`.
5. **Верификация:** После миграции каждой ВМ проверять её доступность и отсутствие ошибок в логах Proxmox.

## 4. Чек-лист выполнения

- [ ] Выполнить `free -h` на обоих узлах для подтверждения текущего состояния RAM.
- [ ] Выполнить `qm list` на `pve01` для получения полного списка ВМ.
- [ ] Идентифицировать ВМ, которые **НЕ** подлежат миграции (компоненты 1С).
- [ ] Выполнить `ceph df` для проверки свободного места в пулах `ceph-fast` и `ceph-bulk`.
- [ ] Составить окончательный список ВМ для миграции на `pve02`.
- [ ] Выполнить миграцию первой ВМ (тестовой или наименее критичной).
- [ ] Проверить доступность мигрированной ВМ.
- [ ] Продолжить миграцию остальных ВМ по списку.

## 5. ⛔ Don't repeat
- Не мигрировать ВМ 1С ERP на `pve02` без явного запроса администратора.
- Не выполнять `qm migrate` при недостатке свободного места на Ceph-пуле назначения.
- Не мигрировать ВМ с привязкой к локальному хранилищу (local/local-lvm) без предварительного переноса дисков на Ceph.
