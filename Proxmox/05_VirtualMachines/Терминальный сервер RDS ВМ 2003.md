# ⚠️ Терминальный сервер RDS работает в льготном периоде — лицензии CAL не куплены

**Критический срок: ~январь 2027** (120 дней с момента установки роли
Session Host, 2026-09-07) — после этой даты сервер перестанет принимать
RDP-подключения без установленных RDS CAL. При обращении к этому документу
после указанной даты — первым делом проверить, куплены ли лицензии.

## Что настроено и зачем
Терминальный сервер (Remote Desktop Session Host) на ВМ 2003 (`TC`,
`TC.KRNN.RU`, Windows Server 2022) для многопользовательских RDP-подключений
сотрудников домена `krnn.ru`.

## Шаги: развёртывание RDS Session Host

**1. Установить роль на `TC.KRNN.RU`:**
```powershell
Install-WindowsFeature -Name RDS-RD-Server -IncludeManagementTools
Get-WindowsFeature -Name RDS-RD-Server
```

**2. Создать RDS Deployment** (Connection Broker и Session Host — один и тот же сервер, только FQDN, не короткое имя):
```powershell
New-RDSessionDeployment -ConnectionBroker "TC.KRNN.RU" -SessionHost "TC.KRNN.RU"
Get-RDServer
```

**3. Создать коллекцию сеансов:**
```powershell
New-RDSessionCollection -CollectionName "Terminal" -SessionHost "TC.KRNN.RU" -ConnectionBroker "TC.KRNN.RU"
Get-RDSessionCollection -ConnectionBroker "TC.KRNN.RU"
```

**4. Разрешить подключение доменной группе:**
```powershell
Add-LocalGroupMember -Group "Remote Desktop Users" -Member "KRNN\Пользователи домена"
Get-LocalGroupMember -Group "Remote Desktop Users"
```
⚠️ `Grant-RDAccess` в этой среде отсутствует — использовать
`Add-LocalGroupMember` напрямую.

## Шаги: сервер лицензирования RDS (на AD.krnn.ru, не на TC)

**1. Установить роль на контроллере домена:**
```powershell
Install-WindowsFeature -Name RDS-Licensing -IncludeManagementTools
```

**2. Активировать сервер лицензий** через мастер активации (Диспетчер
лицензирования удалённых рабочих столов — не запускать как `lsmgr.exe`,
использовать ярлык/полный путь, если команда не находится).

## Настройка режима лицензирования на TC — реальные ошибки и итоговое решение

**Ошибка 1 — не тот cmdlet:**
```powershell
Set-RDSessionCollectionConfiguration -CollectionName "Terminal" -ConnectionBroker "TC.KRNN.RU" -LicensingMode "PerUser" -LicensingServerNames "AD.krnn.ru"
# → Set-RDSessionCollectionConfiguration : Не удается найти параметр, соответствующий имени параметра "LicensingMode".
```
**Верный cmdlet:**
```powershell
Set-RDSessionDeployment -ConnectionBroker "TC.KRNN.RU" -LicensingMode "PerUser" -LicenseServer "AD.krnn.ru"
Get-RDSessionDeployment -ConnectionBroker "TC.KRNN.RU" | Select-Object LicensingMode, LicenseServer
```

**Проблема 2 — Server Manager продолжал показывать предупреждение о
лицензировании**, хотя реестр уже был корректен:
```powershell
Get-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM\Licensing Core" |
  Select-Object LicenseServers, LicensingMode
# → LicenseServers: AD.krnn.ru, LicensingMode: 4 (Per User)
```
**Причина:** служба `TermService` кэширует параметры лицензирования при
старте и не подхватывает изменения реестра «на лету».

**Решение:**
```powershell
Restart-Service -Name TermService -Force
Set-Service -Name TermService -StartupType Automatic
Get-Service -Name TermService | Select-Object Status, StartType
```
Ожидаемый результат: `Status: Running`, `StartType: Automatic`.

**Откат** (если понадобится вернуть службу в ручной запуск):
```powershell
Set-Service -Name TermService -StartupType Manual
```

- [x] Группа `KRNN\Пользователи домена` добавлена в `Remote Desktop Users`, подключение по RDP проверено и работает.

- [ ] **Не куплены и не установлены реальные RDS CAL** — сервер работает в 120-дневном льготном режиме.

## ⚠️ Не забыть (напоминание, не факт)
- Приобрести и установить не менее 10 RDS CAL до истечения льготного периода (~январь 2027).
- После покупки — установить лицензии через Диспетчер лицензирования удалённых рабочих столов на `AD.krnn.ru`.
- Настроить резервное копирование `TC` и `AD` — не было сделано в рамках этой сессии.
- Опционально: политики RDS (перенаправление принтеров/дисков/буфера обмена), ограничение времени сессий, профили пользователей.
