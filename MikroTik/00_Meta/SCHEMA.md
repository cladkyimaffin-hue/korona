# 📐 SCHEMA.md — доменные дополнения (MikroTik)

Общее ядро схемы (обязательные 15 полей, опциональный блок, формат
`document_id`, принцип эволюции, история версий) находится в
[`../../SCHEMA.md`](../../SCHEMA.md). Этот файл содержит только то, что
зависит от домена `MikroTik/`. При противоречии приоритет у корневого файла
— расхождение записывается в `CONFLICTS.md`.

## category

Имя целевой папки домена `MikroTik/` — список в `AI-README.md` этого домена
(раздел «Структура домена/репозитория»).

## Доменные значения опциональных полей

Значения `node`, `cluster`, `hostname` для устройств MikroTik берутся из
файла фактов домена (`AI-environment_facts-*.md`) и `AI-README.md`; в этом
файле они не дублируются, чтобы не расходиться с фактами.

## Теги и реестр

Теги — только из `TAGS.md` этого домена, `document_id` проверяются по
`registry.csv` этого домена.
