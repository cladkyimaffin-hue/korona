# AI-README.md (домен MikroTik)

## Назначение файла

Этот файл объясняет структуру знаний внутри домена `MikroTik/` репозитория
`korona` — порядок поиска информации и назначение документации. Он не
является набором команд для безусловного выполнения.

Обязательные операционные правила — в файле:

    ../AI-INSTRUCTIONS.md   (в корне репозитория, общий для всех доменов)

Если правила этого файла противоречат `../AI-INSTRUCTIONS.md`, приоритет
имеет `../AI-INSTRUCTIONS.md`.

---

## 1. Назначение домена

`MikroTik/` документирует конфигурацию и обслуживание маршрутизатора(ов)
MikroTik RouterOS, обеспечивающего сетевую связность для инфраструктуры
`korona` (включая, но не ограничиваясь, сетью `192.168.200.0/22`, в
которой также находится кластер Proxmox — см. `../Proxmox/`). Домен
независим от `Proxmox/` в части своей документации (свой `00_Meta/`,
свои теги, свой реестр), даже когда описываемое оборудование физически
обслуживает одну и ту же сеть.

## 2. Главная цель ИИ

Дать администратору быстрый, точный и безопасный ответ по конфигурации
MikroTik — с приоритетом на **read-only диагностику** прежде, чем
предлагать изменения (`add`/`remove`/`set` в RouterOS), и на маскировку
секретов (пароли, PPPoE-реквизиты, ключи, токены — как `****`) при любом
анализе вывода `export`/`print`.

## 3. Структура домена

| Папка | Назначение |
|---|---|
| `00_Meta/` | Служебные файлы конвейера — идентичный `Proxmox/00_Meta/` формат, независимые данные |
| `00_Inbox/` | Необработанный сырой материал, ожидающий разбора конвейером |
| `01_Interfaces/` | Интерфейсы, адресация, PPPoE, VLAN, bridge |
| `02_Firewall_NAT/` | Правила Firewall и NAT (src-nat, dst-nat, filter) |
| `03_VPN/` | VPN-туннели (IPsec, L2TP, WireGuard) |
| `04_Routing/` | Статическая и динамическая маршрутизация |
| `05_Troubleshooting/` | Инциденты и их решения |
| `99_Archive/` | Устаревшие документы, помеченные `superseded_by` |

Точный список документов — не в этом файле (см. опыт `Proxmox/AI-README.md`,
где построчный список устаревал при каждом переносе документа):

- `00_Meta/registry.csv` — машиночитаемый;
- `MikroTik/INDEX.md` — человекочитаемая навигация (создаётся по факту появления документов).

## 4. Приоритет источников

1. Явно сформулированное требование пользователя.
2. Текущая конфигурация устройства (`export`/`print` вживую).
3. `AI-environment_facts-korona-mikrotik.md` (подтверждённые факты).
4. Документы этого домена (`registry.csv`/категорийные папки).
5. Официальная документация MikroTik/RouterOS (wiki.mikrotik.com).
6. Общие знания ИИ.

## 5. Как искать ответ

1. Проверить `AI-environment_facts-korona-mikrotik.md` — известные факты и аномалии.
2. Проверить `00_Meta/registry.csv` — нет ли уже документа на эту тему.
3. При отсутствии — работать по протоколу конвейера, `../AI-INSTRUCTIONS.md`, раздел 8а.
