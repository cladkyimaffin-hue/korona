# AI-environment_facts-korona-mikrotik.md

Подтверждённые факты об инфраструктуре MikroTik/RouterOS в составе
`korona`. Формат и роль файла — как у `Proxmox/AI-environment_facts-korona-proxmox.md`:
источник истины для сверки при обработке новых документов (протокол
конвейера, `../AI-INSTRUCTIONS.md`, раздел 8а, шаг 5).

## Устройство
- Платформа: MikroTik RouterOS.
- Внешний интерфейс: `pppoe-out1`.
- Публичный IP (WAN): `89.109.14.221`.

## Сети
- `192.168.200.0/24` — основная внутренняя подсеть (пересекается по
  диапазону с management-сетью кластера Proxmox, `192.168.200.0/22` —
  см. `../Proxmox/AI-environment_facts-korona-proxmox.md`; уточнить при
  аудите точное соотношение этих двух записей — возможно, это одна и та
  же сеть, описанная в двух документах с разной маской).
- `192.168.1.0/24` — дополнительная внутренняя подсеть.
- Доверенный внешний IP источника VDI (после NAT провайдера): `91.217.9.238`.

## Известные аномалии (на момент 2026-09-17, требуют проверки аудитом)
1. Наличие legacy-правил NAT с `dst-address=192.168.199.1` — назначение не подтверждено, кандидат на очистку после проверки.
2. Нерабочее правило NAT `#21` (`src-address=172.19.1.30`), предположительно дублирующее рабочее правило `#22` (`src-address=91.217.9.238`) — не подтверждено, требует сравнения через `print detail`.

## Статус аудита
Полный read-only аудит конфигурации (NAT, Firewall, VPN, Interfaces,
Routing) начат 2026-09-17, результаты — по мере обработки через конвейер
в `05_Troubleshooting/`/`02_Firewall_NAT/` и т.д. Этот раздел дополнять
по факту завершения аудита, а не оставлять как единственную версию
истины дольше, чем нужно.
