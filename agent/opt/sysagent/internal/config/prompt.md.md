### Шаг 18.4 — Создание внешнего системного промпта /opt/sysagent/configs/prompt.md
Выносим системную инструкцию ИИ в отдельный текстовый файл /opt/sysagent/configs/prompt.md с правами 0640. Вы сможете редактировать его в любой момент через nano /opt/sysagent/configs/prompt.md — router.go на следующем шаге будет перечитывать этот файл с диска при каждом запросе без пересборки и без перезапуска демона.
